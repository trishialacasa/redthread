# 🩸 RedThread

**Connecting Lives, One Drop at a Time.**

RedThread is a Flutter-based mobile application prototype designed to provide a simple and organized way to view blood availability and hospital blood bank information.

## 📱 About the Project

RedThread aims to make blood availability information easier to access through a clean, user-friendly interface. The application presents blood types, available units, and sample hospital blood bank details.

## ✨ Features

- **Blood Availability** – Displays eight blood types (A+, A-, B+, B-, O+, O-, AB+, and AB-) with their corresponding available units.
- **Hospital Blood Banks** – Shows sample hospitals, locations, and blood stock statuses.
- **Home Dashboard** – Features a personalized welcome message and organized information cards.
- **Bottom Navigation Bar** – Provides navigation icons for Home, Blood, Requests, and Profile.
- **Consistent UI Design** – Uses a coordinated red-and-pink color theme.

## 🛠️ Technologies Used

- Flutter
- Dart
- Visual Studio Code
- Android Studio Emulator
- Git and GitHub

## 🚀 How to Run

1. Install Flutter SDK and configure your development environment.
2. Clone the repository:

   `git clone https://github.com/trishialacasa/redthread.git`

3. Open the project folder:

   `cd redthread`

4. Install dependencies:

   `flutter pub get`

5. Run the application:

   `flutter run`

## 📌 Project Status

RedThread is currently a static UI prototype using sample blood availability and hospital information. Real-time blood bank monitoring and backend integration are not yet implemented.
